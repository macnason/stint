# Stint playground

A gallery of the component over approximate public careers of well-known
designers, at each orientation and a few widths. Use it to eyeball layout
shift, label spacing and motion against real-world shapes: overlapping
studios, long titles, decades-long tenures, careers with no current role.

```bash
npm run playground
```

Nothing here ships: the playground is outside the npm workspaces and the
package `files` list.

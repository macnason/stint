# Onboarding options

Open `onboarding-options.html` in a browser. It is a self-contained, dependency-free concept mockup comparing:

- **A: Chat first.** Attach or paste history, review it in conversation, receive the finished page from the agent.
- **B: Optional setup window.** Choose a file, edit history in a form, return to the agent for the finished page.

Both panels have independent Previous/Next controls and simulated primary actions. Add `?stage=0`, `?stage=1`, or `?stage=2` to show the same moment in both flows. All career details are fictional; no uploads or project writes occur. The mock chat is illustrative and does not promise control over an agent host's UI.

The PR contains screenshots of all three stages. These compare the proposed experience; the separate wizard recording demonstrates the implemented file-picker route.
